# 来源账号并发和任务续跑

在“能源 → 来源”编辑账号，填写“并发数量”：0 表示不限，正整数表示该账号最多同时执行的上游任务数。同一账号下的所有服务共用这个上限，不同账号独立计数。来源服务的“鉴权账号”支持多选，通用、专用账号都可明确绑定；留空只使用当前来源的启用通用账号，专用账号不会自动混入其他服务。单选固定使用该账号，多选按可用负载分配。

同一服务按账号已用并发占比选择账号，负载相同时按上次分配顺序轮流使用。并发为 0 的账号以在途任务数比较负载。满额账号跳过，所有候选都满额时按服务排队；同一账号在不同服务中的任务共用上限。账号选择与占位由同一个 Redis Lua 操作完成。并发数修改会被等待任务重新读取；降低上限不停止已提交任务，后续任务等待当前数量降到上限以下。排队时间受原任务期限约束，不额外配置排队规则。

画布、智能体、工作流、代理及直接能力调用统一在实际来源调用入口处理。异步图片、视频从提交到上游生成结束占一个名额；查询进度、取消和下载结果不额外占名额，始终使用原执行回执的账号及凭据，不重新参与账号选择。确认上游结束后先保存终态、释放名额，再下载、上传和计费收尾。收尾失败继续使用原结果，不重新生成。

Redis 按账号 ID 保存并发占位，按服务保存等待顺序，执行回执、远端任务号、结果及计费业务键继续保存在数据库。Redis 索引丢失时，先按数据库未完成任务恢复占位。进程失联不会自动释放尚未确认结束的上游任务。认证头、凭据不进入回执或 Redis。多账号调度或设置了并发限制时需要项目 Redis；未启用 Redis 仅允许单个不限并发账号。Redis 已启用但访问失败时明确报错。

执行中、排队和错误通过原有画布、任务及调用记录查看。停止未提交任务会退出队列；停止已提交任务会尝试远端取消，并继续确认终态。取消得到受理不代表远端已经结束。

API 和 Worker 分开运行。浏览器关闭只结束观察，API 重启不停止 Worker 的上游连接。Worker 重启后查询原远端任务，或继续已保存结果的收尾。父运行本地上下文结束不取消已受理的异步子运行。

完整的同步 JSON 响应和异步提交响应在协议解析前保存到原执行回执，只保留响应体及 Content-Type。解析、归一化或收尾期间中断后复用该响应，不重新提交。异步提交响应已保存但任务号尚未解析时，同样从原响应提取任务号并继续查询。

Supervisor 在进程退出后自动拉起。更新 Worker 时先停止领取新任务，等待现有任务及必要子调用完成；期间 API 仍可入库，排队任务由新版 Worker 领取。超过配置的排空期限后取消本地执行，恢复仍遵守数据库租约和原回执。

远程同步调用在发送前保存请求的超时点。执行进程中断、连接断开且没有任务号或响应时，等原请求超时后自动恢复重试一次，总计最多执行两次。重试保留本地任务号、原始参数、计费业务键和任务总期限，重新经过账号并发队列；每次执行使用独立的提交标识，旧进程迟到的回执不能覆盖新执行。明确拒绝、用户取消以及已有回执的任务不重新生成。恢复重试仍未取得回执时明确失败，取消或失败的同步任务在原请求超时后释放本地占位。未提交任务超过总期限也明确结束。

模型返回的异步任务号继续用于查询原任务，已保存响应或结果继续收尾。本地结果提交和扣费按同一任务去重；无回执时的恢复重试可能使模型平台额外生成、收费一次。

OpenAI 兼容来源的图片任务扩展通过服务路径 `images/tasks` 启用：提交读取 `id`，随后查询 `images/tasks/{id}`，识别 `queued/processing/completed/failed`，完成后读取标准 `data[].url` 或 `data[].b64_json`。提交携带原请求号作为 `Idempotency-Key`，查询和恢复复用已有任务号；结果只保留图片数据，不向调用方暴露远端任务中的账号和参考素材。普通 `images/generations` 和 `images/edits` 仍为同步调用，不自动附加 `async`。后台、画布和故事节点共用这条来源调用链，无需增加用户参数。

流式调用收到分片后，先记录响应已开始，再向调用方发送内容。已有部分流式内容的中断任务明确失败并保留已收到内容，不自动重新生成并拼接另一份文本。

本地 FFmpeg 的 CPU 控制、Worker 本身的任务容量继续使用现有运行配置，不属于来源账号的并发设置。
