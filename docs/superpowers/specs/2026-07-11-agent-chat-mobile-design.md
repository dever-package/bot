# Agent Chat 手机端适配

状态：待实施
日期：2026-07-11

## 目标

只调整 `show-agent-chat` 的响应式布局，不修改聊天状态、接口、流式处理和桌面端结构。

## 布局

手机端：

- 会话区域从纵向侧栏变成顶部横向滑动条。
- “新对话”使用固定尺寸图标按钮，会话标题使用单行紧凑按钮。
- 当前会话保持明确选中状态，会话数量不挤压标题。
- 聊天内容和输入区占据剩余高度。

桌面端保持现有左侧会话栏和右侧聊天区。

## 视口与触控

- 默认高度改用 `dvh`，适应手机地址栏和虚拟键盘变化。
- 输入区底部加入 `safe-area-inset-bottom`。
- 手机端发送、停止和新对话按钮至少 40px。
- 手机端输入文字使用 16px，避免 iOS 聚焦时自动缩放；桌面恢复紧凑字号。
- 用户气泡限制最大宽度，长文本和长单词必须换行。

## 范围

只修改：

- `front/src/nodes/show/agent-chat.tsx`

不新增抽屉、依赖或移动端专用状态，不修改后端和页面 API 配置。

## 手动验收

1. 375px 和 430px 宽度下，会话条、消息区和输入区不重叠。
2. 会话较多时可以横向滑动并切换。
3. 弹出手机键盘后仍能看到输入框和发送/停止按钮。
4. 发送、停止和新对话按钮便于触控。
5. 桌面端仍显示左侧会话栏。

按项目要求不运行 build、test 或 lint，只做静态检查。
