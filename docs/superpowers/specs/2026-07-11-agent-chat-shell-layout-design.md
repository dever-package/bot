# Agent Chat 壳层布局设计

状态：已确认
日期：2026-07-11

## 目标

调整全屏智能体聊天的侧栏和输入区，使桌面布局接近参考聊天产品，同时让手机版集中展示当前对话。

## 桌面端

- 左侧使用固定宽度纵向侧栏，不再复用手机版横向布局。
- 侧栏从顶部依次显示智能体名称、“新对话”和历史会话列表。
- 当前会话保持明确选中状态；历史会话区域独立纵向滚动。
- 右侧继续显示当前智能体标题、消息内容和关闭按钮。

## 手机端

- 小于 `md` 断点时完全隐藏左侧栏，不显示顶部会话条。
- 在右侧标题栏增加“新对话”图标按钮，保留创建会话的核心入口。
- 当前阶段不增加抽屉或手机端历史会话切换，避免引入额外状态。

## 输入区

- 输入区使用独立的大圆角 composer，和页面边缘保留稳定间距。
- 发送和停止按钮固定在 composer 右下角，使用明确的圆形按钮和内联稳定尺寸，避免被裁切。
- 发送按钮使用向上箭头；禁用时仍保留可见轮廓和位置。
- 保留多行输入、手机安全区和现有 Enter 发送行为。

## 范围

只修改 `front/src/nodes/show/agent-chat.tsx` 的展示结构和样式。不修改会话 API、流式处理、消息持久化、runtime 和后端。

## 验收

1. 桌面端左侧栏从顶部开始排列，历史会话纵向显示。
2. 手机端不显示左侧栏或顶部会话条。
3. 手机端仍可通过标题栏创建新对话。
4. 发送和停止按钮在空输入、可发送和运行中三种状态下都不会被裁切。
5. 关闭弹窗、历史会话切换和流式输出行为不变。

按项目要求不运行 build、test 或 lint，只执行源码静态检查和 Dever audit。
