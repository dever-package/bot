# 画布暗色模式与分组连线设计

## 目标

- 分组节点沿用功能节点的红色语义：普通连线默认灰色，悬停或选中分组时相关连线变红。
- 画布与 Body 外层共用现有 `useTheme` 设置，任一入口切换后另一处同步。
- 亮色和暗色保持相同的 Paper 布局、字体和组件结构，仅切换语义颜色。

## 方案

画布不增加主题状态。`WorkSpacePage` 继续读取 `resolvedTheme` 并调用共享 `setTheme`；修复集中在 Paper 视觉层：把中性背景、文字、边框、悬停和阴影抽成 CSS 变量，并在 `.ws-page.is-light` 与 `.ws-page.is-dark` 下分别赋值。节点类型的图片、视频和红/绿/蓝/紫等业务强调色保持不变。

连线继续复用 `decorateFlowEdge` 与 `nodeHighlightColor`。只给 `group` 增加与 `function` 相同的红色映射，不改变默认灰线、选中线宽、动画或执行路径算法。

## 范围

暗色变量覆盖画布背景与网格、顶部栏、工具栏、菜单、节点卡片、面板、弹窗、空状态和资产中心等 Paper 中性表面。已有节点数据、画布保存格式和后端执行逻辑不变。

## 验证

项目明确禁止构建和测试命令，因此仅运行 Dever 静态审计、`git diff --check`、残留硬编码扫描和引用检查；交互与视觉由用户手动验证。
